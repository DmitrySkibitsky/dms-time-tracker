## v0.1.0

First release.

### 🚀 Enhancements

- Time tracker plugin for DMS with Clockify provider ([58eb960](https://github.com/DmitrySkibitsky/dms-time-tracker/commit/58eb960))
  - Bar widget with the running time and description, today's total when idle; right click starts or stops the timer.
  - Timer: description with suggestions from recent entries, project, task, searchable tag picker, billable flag remembered between timers; edit the running entry, including its start time.
  - History grouped by day with totals: continue, edit, duplicate or delete entries; add time manually with start/end or a duration.
  - Several accounts with a quick switch; per-account workspace, default project and billable default; Clockify workspace rules enforced.
  - Settings, Control Center tile and IPC commands (`toggle`, `start`, `stop`, `continueLast`, `status`, `account`).
  - English, Russian and Ukrainian translations.
